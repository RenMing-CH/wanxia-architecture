# 数据与权限边界

本文件用于说明产品概念中的数据类别与作者控制权，不是数据库设计文档。

| 类别 | 内容 | 是否自动成为正式资料 |
|---|---|---|
| 作者正文 | 作者撰写或导入的小说文本 | 正文由作者维护；模型不应擅自改写 |
| 模型候选 | 模型基于任务提出的候选信息 | 否，必须经过作者审核 |
| 已确认资料 | 作者明确接受或修订后确认的内容 | 是，可供后续工作台参考 |
| 作者手记 | 批注、提醒、灵感和个人备注 | 否，不自动变成剧情事实 |
| 数值参考 | 数量、单位、归属主体等参考信息 | 仅在作者核对并确认后可作为有效记录 |
| 世界位面与时间线 | 作者维护的空间、事件和时间表达 | 以作者保存的内容为准，不自动裁定事实 |

## 作者控制原则

1. 作者可以接受、修改或拒绝模型提出的候选内容。
2. 未经确认的模型结果不得伪装成正式资料。
3. 作者手记与正文事实分离；添加批注不意味着修改正文。
4. 数值需要核对来源、单位和归属主体。
5. 世界位面与时间线是作者的组织工具，不自动推进剧情。
6. 对来源不明或存在冲突的内容，应提示作者检查，而不是自行编造结论。

## 隐私与公开原则

公开演示仓库只包含经过挑选和处理的界面截图及抽象说明。任何真实小说正文、用户数据、访问凭证、内部提示词、私有测试数据或可还原内部实现的文件都不应进入公开仓库。
