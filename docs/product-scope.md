# 产品范围与状态说明

状态标签说明：

- **已验收：** 有明确的本机功能验收记录。
- **界面演示：** 截图展示了界面或交互方向，但本仓库不据此承诺全部功能已正式发布。
- **规划中：** 未来产品方向，不应描述为当前可用功能。

## 小说剧情连续化提取

**产品定位：** 将章节内容整理为候选资料，经作者审核后形成可追溯、可复用的资料，并在后续章节中持续维护。

**公开说明：** 采用多模型、多轮次、分步骤任务路由；强调职责拆分、阶段边界、候选审核和作者最终确认。

**不公开：** 具体卡片体系、字段目录、内部身份分配方式、提示词、路由表和后端数据结构。
