# 卡片档案示例

以下三张截图由作者选定，来自隔离测试集，用于展示卡片版本演进和资料展示方式。示例不是完整卡片模板、字段目录或内部数据结构。

## 1. 档案版本记录

![档案版本记录](../assets/card-examples/card-version-history.webp)

展示同一档案的当前版本、历史版本、来源章节和不同版本涉及的字段变化。重点是让作者能够回看资料如何随着章节推进而演进。

## 2. 地点卡

![地点卡](../assets/card-examples/location-card.webp)

展示地点类型、地理位置、固定设施与资源、当前状态及关联角色。

## 3. 角色卡

![角色卡](../assets/card-examples/character-card.webp)

展示人物身份、所属组织、能力、持有物、经历、所在位置、当前状态和人际关系。

## 截图边界

- 截图来自隔离测试集，不代表真实小说正文或真实用户资料。
- 图片只展示经作者选定的视觉示例，不构成可直接复刻的完整模板。
- 不包含内部 Prompt、永久身份分配规则、数据库结构或 API 契约。
- 本次公开仅收录以上三张卡片示例，不代表其他工作台模块均已正式发布或部署。
