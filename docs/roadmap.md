# 路线图

本路线图描述产品方向，不构成发布日期或功能交付承诺。

## 近期方向：人设与角色辅助

帮助作者维护人物设定、关系和状态变化，并保持资料可审阅、可修订、可追溯。作者仍然决定人物动机、行为和命运；系统不应擅自替作者补写人物事实。

## 未来方向：文字游戏

将文字叙事扩展为互动体验，支持作者规划文本节点、选择与反馈。具体交互形式、创作流程和运行方式仍待后续设计与验证。

## 概念方向：一句话生成自己的文字游戏

用户用一句话描述想做的游戏，例如题材、核心玩法或体验目标。系统协助形成一个可继续编辑的初始方案，再由作者调整内容和规则。

这项能力目前属于路线图概念，不代表现有版本已支持完整生成、运行、保存或发布。

## 不变的产品原则

- 作者拥有最终决定权。
- 模型生成内容应可检查、可修改、可拒绝。
- 不把未经确认的内容写入正式资料。
- 新模块必须明确输入、输出、职责和权限边界。
